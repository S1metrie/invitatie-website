# Invitatie Website

Acest depozit contine mai multe pagini HTML si fisiere CSS pentru un site simplu. Pentru a vedea pagina cu haine termice, deschideti fisierul `haine-termice.html` intr-un browser web.

1. Descarcati sau clonati acest depozit pe calculatorul dumneavoastra.
2. Deschideti folderul in care se afla si dati dublu click pe `haine-termice.html`.
3. Pagina se va deschide in browser si veti putea vizualiza produsele.

In mediul curent Codex nu poate lansa un browser cu interfata grafica, de aceea este necesar sa urmati pasii de mai sus pe propriul calculator.
